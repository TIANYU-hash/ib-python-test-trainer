# Python Test 1 — Practice Trainer

Interactive revision for IB CS HL Test 1 (CodeHS Units 3, 5, 7, 9, 10, 12, 13 2D lists).

## Open it

From this folder in Terminal:

```bash
cd ~/Desktop/CS/python-test-trainer
python3 -m http.server 8080
```

Then in your browser: **http://localhost:8080**

Use the local server (required). Skulpt is bundled in `vendor/` so you only need internet once — or none if files are already there.

**Hard refresh after updates:** `Cmd + Shift + R`

## Features

- CodeHS-aligned exercises + **Constructs** section (pairs, duplicates/sets, search, Big O halvings)
- **Run** — see stdout
- **Check** — compares output or runs hidden tests (like CodeHS)
- Progress saved in your browser (localStorage)
